# Datastraw Assignment — AI Voice CX Agent (Aura Skincare)

An enterprise-grade, browser-based AI Voice Customer Experience (CX) Agent built for **Aura Skincare**, a premium Indian D2C organic skincare brand.

## Key Capabilities
- 🎙️ **Natural Voice Interaction**: Real-time conversation with an authentic Indian voice persona (*Aria*).
- ⚡ **Low Latency & Barge-In**: Sub-second response cadence with instantaneous speech interruption handling.
- 📦 **Order Lookup & Live State Synchronization**: Real-time function calling for order status, cancellations, and returns.
- 🛡️ **Deterministic Brand Guardrails**: Business logic and brand policies enforced in code to prevent hallucinated commitments.
- 📊 **Post-Call Telemetry**: Automatic generation of chronological transcripts and structured CRM JSON summaries.
- 🖥️ **Multi-Page CX Operations Suite**: Dedicated interfaces for Live Voice Studio, Order Management (OMS), Policy Directory, and Analytics.
